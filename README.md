# Maze Solver using A* Search

## Overview
This project is a Python implementation of the A* (A-Star) Search Algorithm used to find the shortest path through a maze. The maze consists of a start point (`S`), a goal (`G`), open paths (`.`), and obstacles (`#`).

The algorithm uses the Manhattan Distance heuristic to efficiently search for the optimal path.

## Features
- Finds the shortest path in a maze
- Uses the A* Search Algorithm
- Handles obstacles and walls
- Prints the solved maze
- Detects when no path exists

## Technologies Used
- Python 3
- A* Search Algorithm
- Manhattan Distance Heuristic

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/adamsaeed2008-jpj/maze-solver-a-star.git
   ```

2. Navigate to the project folder:
   ```bash
   cd maze-solver-a-star
   ```

3. Run the program:
   ```bash
   python main.py
   ```
